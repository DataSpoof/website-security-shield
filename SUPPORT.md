# Support

- **Questions / how-to:** open a [Discussion](https://github.com/DataSpoof/website-security-shield/discussions) or a non-bug issue.
- **Bugs:** use the Bug report issue template.
- **New coverage / techniques:** use the Improvement issue template (include a framework mapping).
- **Security vulnerabilities in this project:** do **not** file a public issue — see [SECURITY.md](SECURITY.md).
- **Authorized-use questions:** read [SCOPE.md](SCOPE.md). This project does not help attack systems you don't own or aren't authorized to test.

Response is best-effort. Please search existing issues/discussions first.
